🔧 Configurar Cloudflare Worker como proxy R2

Solución al problema CORS: api.cloudflare.com no acepta llamadas desde el browser

¿Por qué un Worker?
La API REST de Cloudflare (api.cloudflare.com) bloquea llamadas CORS desde browsers. Un Cloudflare Worker actúa como proxy: recibe las peticiones desde el browser, las reenvía a R2 internamente (sin CORS), y devuelve el resultado. Es gratis, tarda 2 minutos en configurar, y queda disponible para siempre.

Paso 1 — Crear el Worker

1

Ve a dash.cloudflare.com → Workers & Pages → Create

2

Selecciona "Create Worker", nómbralo r2-proxy-casamota

3

Haz clic en "Edit code" y reemplaza TODO el contenido con este código:

// Dominios desde los que se admite subir. La tienda responde con y sin "www",
// asi que las dos formas son legitimas y las dos tienen que estar aqui.
const ORIGENES = [
  'https://supermercadocasamota.com',
  'https://www.supermercadocasamota.com',
];

export default {
  async fetch(request, env) {
    // Access-Control-Allow-Origin admite UN solo valor, nunca una lista. Con
    // varios dominios validos hay que mirar de donde viene la peticion y, si
    // esta en la lista, devolver ese mismo origen.
    const origen = elegirOrigen(request);

    // CORS preflight
    if (request.method === 'OPTIONS') {
      return new Response(null, { headers: corsHeaders(origen) });
    }

    const url = new URL(request.url);
    // Esperamos rutas: /put/{key}  (body = imagen binaria)
    const path = url.pathname; // e.g. /put/productos/abc123.jpg

    if (!path.startsWith('/put/')) {
      return new Response('{"error":"invalid path"}', {
        status: 400,
        headers: corsHeaders(origen)
      });
    }

    const key = path.slice(5); // quitar "/put/"

    if (request.method !== 'PUT') {
      return new Response('{"error":"method not allowed"}', {
        status: 405,
        headers: corsHeaders(origen)
      });
    }

    // 1. Token compartido. Se configura en Cloudflare como variable de entorno
    //    (UPLOAD_TOKEN), no va escrito aqui. Sin token no se sube nada.
    if (!env.UPLOAD_TOKEN || request.headers.get('x-upload-token') !== env.UPLOAD_TOKEN) {
      return new Response('{"error":"unauthorized"}', {
        status: 401,
        headers: corsHeaders(origen, 'application/json')
      });
    }

    // 2. Solo se admite escribir dentro de productos/. Sin esto el bucket puede
    //    usarse para alojar cualquier fichero bajo el dominio propio.
    //    Se rechaza tambien ".." para que nadie salga de la carpeta.
    if (!key.startsWith('productos/') || key.includes('..')) {
      return new Response('{"error":"key not allowed"}', {
        status: 403,
        headers: corsHeaders(origen, 'application/json')
      });
    }

    // 3. Solo imagenes.
    const ct = request.headers.get('Content-Type') || '';
    if (!ct.startsWith('image/')) {
      return new Response('{"error":"content-type must be image/*"}', {
        status: 415,
        headers: corsHeaders(origen, 'application/json')
      });
    }

    try {
      const body = await request.arrayBuffer();

      // 4. Nada vacio. Antes se guardaba un objeto de 0 bytes y se respondia
      //    ok:true, dejando en la base de datos una URL que no muestra nada.
      if (!body.byteLength) {
        return new Response('{"error":"empty body"}', {
          status: 400,
          headers: corsHeaders(origen, 'application/json')
        });
      }

      // 5. Tope de tamano: 6 MB. Evita que un fallo o un abuso llene el bucket.
      if (body.byteLength > 6 * 1024 * 1024) {
        return new Response('{"error":"file too large (max 6 MB)"}', {
          status: 413,
          headers: corsHeaders(origen, 'application/json')
        });
      }

      await env.R2_BUCKET.put(key, body, {
        httpMetadata: { contentType: ct }
      });

      return new Response(
        JSON.stringify({ ok: true, key, size: body.byteLength }),
        { status: 200, headers: corsHeaders(origen, 'application/json') }
      );
    } catch(e) {
      return new Response(
        JSON.stringify({ ok: false, error: e.message }),
        { status: 500, headers: corsHeaders(origen, 'application/json') }
      );
    }
  }
};

// Devuelve el origen de la peticion si esta autorizado. Si no lo esta, devuelve
// el dominio principal: asi el navegador bloquea la respuesta, que es lo que se
// busca, en lugar de abrirla a cualquiera con un comodin.
function elegirOrigen(request) {
  const o = request.headers.get('Origin');
  return ORIGENES.includes(o) ? o : ORIGENES[0];
}

function corsHeaders(origen, ct) {
  const h = {
    'Access-Control-Allow-Origin': origen,
    'Access-Control-Allow-Methods': 'PUT,OPTIONS',
    'Access-Control-Allow-Headers': 'Content-Type,x-upload-token',
    'Access-Control-Max-Age': '86400',
    // La respuesta cambia segun el Origin. Sin esto una cache intermedia podria
    // servir a un dominio la cabecera calculada para el otro.
    'Vary': 'Origin',
  };
  if (ct) h['Content-Type'] = ct;
  return h;
}
4

Clic en "Deploy"

Paso 2 — Vincular bucket R2 al Worker

5

En el Worker creado → pestaña "Settings" → "Bindings"

Clic en "+ Add" → selecciona "R2 bucket"

6

Configura el binding:

  • Variable name: R2_BUCKET
  • R2 bucket: casamota-imagenes

Clic "Save" → luego "Deploy" de nuevo
