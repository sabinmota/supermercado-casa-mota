¿Cómo usar este backup?

  1. Selecciona las tablas que deseas exportar (o usa Seleccionar todo)
  2. Presiona Exportar seleccionadas y espera que termine
  3. Descarga el archivo casamota-backup-[fecha].json
  4. Guarda el archivo en tu PC junto con los archivos del proyecto
  5. Para restaurar: importa el JSON en Supabase (SQL Editor → INSERT) o usa DB.saveProduct() / DB.saveOrder() según la tabla

Nota: el respaldo incluye también los registros marcados como borrados (deleted), para que sea fiel a la base de datos y no una vista filtrada de la tienda.

¿Por qué pesa tanto? Las imágenes de los productos se guardan dentro de la propia base de datos (base64), así que van incluidas en el JSON. Un respaldo completo ronda los 20 MB: es lo esperado, y significa que también recuperarías las fotos.
